Cette version améliore en profondeur les codes-barres et l'adaptation aux étiquettes.

Codes-barres :
- Nouveaux formats au choix, par cellule : EAN-13, EAN-8, UPC-A, Code 128, Code 39 et QR.
- Génération conforme aux normes : vos codes sont lus correctement par les douchettes.
- Les chiffres sont désormais calés sous les barres, comme sur une étiquette magasin.
- Nouvelle option « Code sur toute la largeur » pour les codes longs, et la taille règle maintenant la dimension du code.
- Alerte quand un code risque d'être trop petit pour être lu, et aide au choix du bon format.

Étiquettes et impression :
- Rouleau continu : la hauteur suit le contenu, sans espace inutile.
- Étiquette prédécoupée : tout le contenu s'adapte pour tenir dans l'étiquette, plus rien n'est coupé.
- QR code plus jamais tronqué, et texte sous le code toujours visible.
