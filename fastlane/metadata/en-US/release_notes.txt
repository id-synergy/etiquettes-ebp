This version greatly improves barcodes and how labels adapt.

Barcodes:
- New per-cell formats: EAN-13, EAN-8, UPC-A, Code 128, Code 39 and QR.
- Standards-compliant generation: your codes scan reliably at the checkout.
- Digits are now aligned under the bars, like a real store label.
- New "Full-width code" option for long codes, and size now controls the code's dimensions.
- Warning when a code may be too small to scan, plus guidance to pick the right format.

Labels and printing:
- Continuous roll: height follows the content, with no wasted space.
- Die-cut label: all content scales to fit the label, nothing is cut off.
- QR code is never truncated, and the text under the code stays visible.
